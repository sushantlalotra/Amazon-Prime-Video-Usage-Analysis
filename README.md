# 🎬 Amazon Prime Video Userbase - Usage Analysis | Power BI Project

## 📊 Project Overview
This project analyzes the userbase and usage patterns of **Amazon Prime Video**, providing insights into user engagement, viewing trends, subscription behavior, and content preferences. Using Power BI, the dashboard helps in understanding audience demographics, retention rates, and top-performing content.

---

## 🎯 Key Objectives
1. Analyze user engagement patterns based on watch time, content type, and demographics.
2. Identify popular genres, movies, and TV shows among different audience segments.
3. Evaluate subscription trends, retention rates, and churn analysis.
4. Provide actionable insights for content strategy and customer retention.

---

## 🚀 Features
- **Dashboard Highlights**:
  - **User Engagement**: Total watch time, peak viewing hours, and session duration.
  - **Subscription Analysis**: Growth trends, active vs. inactive users, and churn rate.
  - **Content Performance**: Popular genres, trending movies/series, and ratings.
  - **Demographic Breakdown**: Viewership by age group, location, and device type.
- **Interactive Reports**:
  - Filter data by subscription type, region, content category, and time period.
  - Drill-through analysis for user-level insights.

---

## 🛠 Tools Used
- **Power BI**: For data visualization and user behavior analysis.
- **Excel/MySQL**: Data sources for storing and preprocessing user engagement data.
- **DAX (Data Analysis Expressions)**: For advanced KPIs and calculated measures.
